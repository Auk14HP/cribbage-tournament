# React for the organizer and display routes

The organizer and display routes are React components; the Tournament core stays plain TypeScript with no React or browser imports, and the routes read it through the storage adapter via `useSyncExternalStore`. We started with hand-written DOM updates, which was fine for registering Players but was already hand-managing edit state and focus on one screen, and the coming screens (both brackets, the TV cycle, Now playing, one-tap results, undo, Forfeit, Losers Bracket opt-in) would multiply that bookkeeping. We switched before building them, while only the two route files had to be rewritten. The core and its tests were untouched by the switch, and should stay that way: React lives only in the routes and the hooks they use.
